# Build the 0.3.38 beta

Prerequisites: Windows, .NET SDK 3.1.426, Python 3 and Zig 0.13.0. Install the Tizen tooling needed by the package references. The managed project pins Tizen.NET.Sdk 1.1.9, Tizen.NET 5.0.0.14562 and Tizen.NET.TV 4.4.0.1341. These old dependencies are retained for the tested TV target. The library model checks additionally use .NET 8.

From the source root in PowerShell:

```powershell
$env:TIZENPS_ZIG = 'C:/path/to/zig.exe'
python pcsx-rearmed-native/tizen-build/build-core.py
```

This builds `pcsx-rearmed-native/tizen-build/libpcsx_tizen.so`. The release source has been rebuilt with a clean cache and matched the bundled core byte-for-byte:

`f4ddeada13923de8cfe6ee2cfd2e662fa0cedd2d8f1f58b7749d8d9fbb3e69ff`

For an unchanged rebuild, compare this file with `roelofs-psx-native/res/libpcsx_tizen.so`. For a modified core, copy the output to that resource path and update `res/core.sha256` and `provenance.json`. Do not label a modified binary as an unchanged official release.

```powershell
Set-Location roelofs-psx-native
dotnet restore Player.csproj
dotnet build Player.csproj -c Release
```

The package appears in `bin/Release/tizen50/`. Re-sign it for your TV with your own identity through Apps2Samsung or the appropriate Tizen tooling. Private keys and certificates are not supplied. A package build and host tests do not establish TV runtime compatibility.

## Artwork

Pre-rendered original artwork is included, so Node is not required to build the app. Editable original covers and emblem are generated by `tools/render-public-art.cjs`; it needs Playwright and Edge. `TIZENPS_PLAYWRIGHT` can point to a Playwright installation. Run `tools/render-tizenpsx-wordmark.ps1` afterward for the current white TizenPSX wordmark. `tools/make-ui.ps1` is the source of the procedural background and framing assets. Do not disable security software if it blocks a build helper; use the included assets while investigating the block.

## Checks

Run `dotnet run --project Check.csproj -c Release` from `library-scan-checks`, `library-ui-checks`, `psx-player-checks`, `dualsense-checks`, `fullspec-checks`, `performance-elf-checks` and `audio-checks`. UI scene export needs an `outputs` directory at the source root. From `tests`, `dotnet run --project LibraryChecks.csproj -- ../roelofs-psx-native/res/catalog.tsv` runs the library model tests using the SDK pinned in that directory.

The emulator is based on libretro/pcsx_rearmed commit `7b0e8f8fadfbce3d170d195b9d9eecaabfa08c8e`. The complete modified source is under `pcsx-rearmed-native`, including the Tizen host, dynarec changes and build script. `toolchain-glibc-source` contains the corresponding glibc wrapper/header subset, including its licenses. Zig is an external build prerequisite, not shipped in the app.
