# Public artwork

This beta bundles original abstract title placeholders, a geometric play emblem, a white TizenPSX wordmark and procedural interface graphics. Their editable sources are in `tools/`. The software's GPLv2 license covers these original project assets. No font files are bundled; renderers use fonts installed on the build machine.

Commercial cover caches, official console emblems and personal library images are excluded from this source export and package. The app still supports local artwork beside the user's game files. Users must obtain any permissions required for those images themselves.

Game titles and publisher metadata are identifiers, not an affiliation or endorsement claim. A screenshot containing third-party cover artwork is a separate publication decision: attribution and a disclaimer alone do not establish redistribution permission. Previously posted personal-library screenshots are not assets included in this beta.
