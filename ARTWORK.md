# Public artwork

All application PNGs in this public edition are original procedural geometric artwork generated by render-public-art.py, GPL-2.0. No downloaded game covers, game characters, manufacturer logos, product photographs or font files are used by this generator. Public-art.json records every generated image. User-supplied USB cover lookup remains in the application. Vendored upstream source assets retain their upstream licenses. Previous Git history may still contain historical screenshots; this publication does not rewrite history.
