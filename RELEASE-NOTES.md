# TizenPSX 0.3.38 beta

First public beta candidate, based on the working 0.3.37 application.

- USB library discovery, carousel/grid, favourites, recent games and per-game settings.
- Original default artwork and geometric branding for public distribution.
- Corresponding source, build instructions, licenses and package checksums.
- Same native emulator core as the developer-tested build; no new performance tuning.

The developer reports that most games tested work well. This is not a claim of 99% compatibility. Other devices, games and controllers remain unverified. CHD, compressed game archives and a complete disc-switching workflow are not supported. No BIOS, commercial games or commercial covers are supplied.

Install the TPK through Apps2Samsung, keeping your existing signing identity for updates. Back up saves and do not uninstall the previous app first. The source archive is supplied alongside the binary under the included licenses.

Exact 0.3.38 TV smoke test: pending. Host validation and byte-identical native-core rebuild are recorded in `VALIDATION.md`.
